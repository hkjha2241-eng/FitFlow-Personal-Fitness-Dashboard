Q1. Explain the HTTP Request–Response Cycle with a suitable diagram. Describe the major steps involved when a client (browser) requests a resource from a web server and receives a response.

Answer:

HTTP stands for hyper text transfer protocol.It is the process in which a browser sends a request to a web server and gets a response.

These are the following steps:-
1)User
2)Browser
3)HTTP Request
4)Web Server
5)HTTP Response
6)Web Page

The user enters a URL in the browser. The browser sends a request to the server. The server processes the request and sends the required webpage as a response. The browser then displays the webpage.


Q2. Briefly explain the purpose and key features of the following web technologies:
1. HTML
2. CSS
3. JavaScript
4. Bootstrap
5. jQuery
6. React.js

Answer:

1. HTML

HTML stands for Hypertext Markup Language. It is used to make the basic structure of a webpage like headings, paragraphs, images, links and tables.

2. CSS

CSS stands for Cascading Style Sheets. It is used to style a webpage such as colors, fonts, spacing and layout.

3. JavaScript

JavaScript is used to make webpages interactive. It can handle clicks, change content and perform different actions.

4. Bootstrap

Bootstrap is a frontend framework which provides ready-made styles and components. It is also useful for making responsive websites.

5. jQuery

jQuery is a JavaScript library which makes tasks like changing HTML elements, events and animations easier.



Q3. What are client-side technologies and server-side technologies? Explain the difference between them with suitable examples.

Answer:

Client-side technologies mainly run in the user browser. They are used for the visible part of the website and user interaction. Examples are HTML, CSS and JavaScript.

Server-side technologies run on the web server. They are used for processing requests, handling data and backend work. Examples are Node.js, PHP and Python.

Client-side runs in the browser, while server-side runs on the server.


Q4. What are block-level elements in HTML? Explain their characteristics and provide at least three examples.

Answer:

Block-level elements normally start from a new line and take the available width of the container.

Examples are <div>, <p>, <h1>, <section> and <article>.


Q5. What are semantic elements in HTML? Explain their importance in web development and provide suitable examples.

Answer:

Semantic elements are HTML elements whose names tell about the content inside them. They make the structure of a webpage easier to understand.

Examples are <header>, <nav>, <section> and <footer>.

They also help search engines and screen readers understand the webpage better.

Q9. Differentiate between HTML, CSS, and JavaScript based on their role in developing a web page. Explain what each technology contributes to a website.

Q10. Answer the following:

a. What is the role of Bootstrap in web development?

b. What is jQuery and why was it widely used in web development?

c. What is React.js and what problem does it solve in frontend development?

React.js is a JavaScript library used for building user interfaces. It uses reusable components, which makes large and interactive frontend applications easier to manage.
