Q1. What is a closure in JavaScript? Explain with a suitable example.

A closure is a feature in JavaScript in which an inner function remembers and can access variables from its outer function, even after the outer function has finished executing.

Example:

function outer() {
    let count = 0;

    function inner() {
        count++;
        console.log(count);
    }

    return inner;
}

let counter = outer();
counter(); // Output: 1
counter(); // Output: 2

Explanation:
The inner() function can still access the count variable of outer() after outer() has finished running. This happens because of a closure. Closures are useful for data privacy and maintaining values between function calls.


Q2. What is a Promise in JavaScript? Explain its different states.

A Promise is a JavaScript object that represents the result of an operation that may finish in the future. It is commonly used to handle asynchronous tasks, such as fetching data from a server.

A Promise has three states:

1. Pending: The operation is still running and the result is not available yet.
2. Fulfilled: The operation has completed successfully, and a result is available.
3. Rejected: The operation has failed, and an error or reason is provided.

Example:

let myPromise = new Promise((resolve, reject) => {
    let success = true;

    if (success) {
        resolve("Task completed successfully");
    } else {
        reject("Task failed");
    }
});

myPromise
    .then(result => console.log(result))
    .catch(error => console.log(error));

Explanation:
resolve() is used when the task succeeds, while reject() is used when it fails. The then() method handles a successful result, and catch() handles an error.


Q3. What is async/await in JavaScript? How does it simplify working with Promises?

Async/await is a way to work with Promises in JavaScript using a simpler and more readable style.

- The async keyword is written before a function to make it return a Promise.
- The await keyword pauses the execution of that async function until the Promise settles and gives its result.
- await can be used inside an async function.

Example:

function getData() {
    return new Promise(resolve => {
        setTimeout(() => {
            resolve("Data received");
        }, 1000);
    });
}

async function showData() {
    let result = await getData();
    console.log(result);
}

showData();

Explanation:
The await keyword waits for getData() to complete before moving to the next line in showData(). It makes asynchronous code easier to read and understand than using multiple then() methods. Errors can be handled with try...catch.


Q4. What is the Global Execution Context in JavaScript?

The Global Execution Context (GEC) is the first execution context created when a JavaScript program starts running. It provides the global environment in which the code is executed.

It has two main phases:

1. Creation Phase: JavaScript sets up memory for variables and functions. Function declarations are stored, and variables declared with var are initially set to undefined.
2. Execution Phase: JavaScript executes the code line by line and assigns values to variables.

The Global Execution Context also provides access to the global object. In a browser, the global object is window. In other JavaScript environments, it may be different.

Example:

var name = "Rahul";

function greet() {
    console.log("Hello " + name);
}

greet();

Explanation:
When this program starts, the Global Execution Context is created. It stores the global variable name and the function greet(), and then the code is executed.


Q5. What is currying in JavaScript? Explain with an example.

Currying is a technique in JavaScript in which a function that takes multiple arguments is converted into a series of functions. Each function takes one argument at a time.

Example:

function add(a) {
    return function(b) {
        return a + b;
    };
}

let result = add(5)(3);
console.log(result); // Output: 8

Explanation:
The first function takes 5 and returns another function. The second function takes 3 and adds it to 5. The final result is 8.

Currying is useful for reusing functions and creating functions with fixed values.


Q6. What is jQuery, and what is its significance in web development?

jQuery is a fast and lightweight JavaScript library. It makes common tasks such as selecting HTML elements, handling events, creating animations, and making AJAX requests easier.

Significance of jQuery:

1. It provides simple syntax for selecting and changing HTML elements.
2. It makes event handling easier.
3. It provides built-in methods for animations and effects.
4. It simplifies AJAX requests for sending and receiving data without reloading a page.
5. It helps handle differences between older web browsers.

Example:

$("#message").hide();

Explanation:
This jQuery statement selects the HTML element with the ID message and hides it.

Although modern JavaScript can do many of these tasks without jQuery, jQuery is still used in some existing websites and projects.


Q7. What is a component in React? Explain its types.

A component in React is a reusable and independent part of a user interface. A component can contain HTML-like JSX, JavaScript logic, and styling. A React application is usually built by combining many components.

The two commonly taught types of components are:

1. Functional Components: These are JavaScript functions that return JSX. They can use React Hooks to manage state and other React features.

Example:

function Welcome() {
    return <h1>Welcome to React</h1>;
}

2. Class Components: These are JavaScript classes that extend React.Component and use a render() method to return JSX. They can manage state and use lifecycle methods.

Example:

class Welcome extends React.Component {
    render() {
        return <h1>Welcome to React</h1>;
    }
}

Functional components are generally preferred in modern React development because they are simpler and support Hooks.


Q8. What is the Virtual DOM? How does it improve application performance?

The Virtual DOM is a lightweight, in-memory representation of the real DOM. React uses it to keep track of changes in the user interface.

When a component's data changes, React creates an updated Virtual DOM and compares it with the previous version. This comparison is called reconciliation. React then updates the necessary parts of the real DOM.

How it helps:

1. It helps React identify which parts of the interface have changed.
2. It avoids unnecessary updates to unchanged parts of the real DOM.
3. It makes UI updates more efficient in many situations.
4. It helps developers build interfaces using a declarative approach.

The Virtual DOM does not make every application automatically faster. Its main benefit is helping React manage and apply UI changes efficiently.


Q9. What is JSX? Why can browsers not understand it directly?

JSX stands for JavaScript XML. It is a syntax extension used in React that allows developers to write HTML-like code inside JavaScript.

Example:

function App() {
    return <h1>Hello World</h1>;
}

Browsers cannot understand JSX directly because JSX is not standard JavaScript syntax. It must be transformed into regular JavaScript by a tool such as Babel or a build tool.

After transformation, the JSX above is converted into JavaScript code that creates React elements.

Benefits of JSX:

1. It makes React code easier to read.
2. It allows developers to describe the user interface clearly.
3. It keeps related UI structure and logic together.
4. JavaScript expressions can be written inside curly braces.


Q10. What are props in React? Are they mutable or immutable?

Props, short for properties, are used to pass data from a parent component to a child component in React. They allow components to receive information and display it.

Example:

function Student(props) {
    return <h2>Name: {props.name}</h2>;
}

function App() {
    return <Student name="Aman" />;
}

Explanation:
The App component passes the value "Aman" to the Student component through the name prop. The Student component receives it using props.name.

Props are immutable from the child component's point of view. This means a child component should not change the props it receives. If the data needs to change, the parent component should update its state and pass the new value as props.
